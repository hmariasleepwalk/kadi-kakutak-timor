## 📝 Deskrisaun Projetu
**Kadi Kakutak** mak aplikasaun game kestaun (quiz) ida ne'ebé kria uza framework **Flutter**. Objetivu prinsipál husi projetu ne'e mak atu promove edukasaun kona-ba istória Timor-Leste nian ba foin-sa'e sira liuhosi dalan ne'ebé interativu, divertidu, no modernu.

Aplikasaun ne'e ajuda utilizadór sira atu koko sira-nia koñesimentu kona-ba eventu importante, figura xave, no jornada luta ba independénsia Timor-Leste.

## ✨ Karakterístika (Features)
- **Kestaun Interativu:** Pergunta oioin kona-ba istória rai Timor.
- **Feedback Instantâneo:** Hatene kedas resposta ne'ebé loos ka sala.
- **Interface Simples:** Dezeñu ne'ebé fasil atu uza (User-friendly).
- **Edukativu:** Foka liu ba informasaun ne'ebé loos hodi aumenta koñesimentu.

## 🛠️ Teknolojia ne'ebé uza
- **Linguajen:** [Dart](https://dart.dev/)
- **Framework:** [Flutter](https://flutter.dev/)
- **Editór:** JDoodle (Online Editor) / VS Code

## 🚀 Oinsá atu Ezekuta (Run)
Se ita-boot hakarak koko kódigu ne'e iha ita-nia komputadór:

1. Instala [Flutter SDK](https://docs.flutter.dev/get-started/install).
2. Kria projetu foun: `flutter create kadi_kakutak`.
3. Kopia kódigu husi `main.dart` iha repositóriu ne'e ba `lib/main.dart` iha ita-nia projetu.
4. Ezekuta uza komandu:

   flutter run
